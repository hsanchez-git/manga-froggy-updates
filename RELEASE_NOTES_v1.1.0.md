# Manga Froggy 1.1.0

- Lectura online de capítulos disponibles en español.
- Biblioteca, historial y progreso de lectura locales.
- MangaDex y fuentes gestionadas por Source Manager.
- Definiciones de fuentes actualizables mediante el flujo firmado existente.
- Comprobación manual de nuevas APK desde Ajustes → Actualizaciones.
- Exportación e importación local de copias de seguridad.

La consulta de actualizaciones por Internet se activará al publicar el manifest
firmado en GitHub Pages. La primera instalación con la firma RELEASE estable se
hará una sola vez tras desinstalar la instalación firmada con la clave antigua.
